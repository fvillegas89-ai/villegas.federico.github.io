# Bitácora de Inteligencia Artificial

## Consulta 1
- **Fecha:** 11/11/2026
- **Herramienta utilizada:** ChatGPT / Gemini
- **Objetivo:** Generar la estructura básica de HTML5 con etiquetas semánticas[cite: 1].
- **Prompt completo:** "Necesito una estructura semántica para un portfolio con encabezado, navegación, presentación, sobre mí, proyectos, habilidades, contacto y pie de página. Usá solamente HTML5, sin CSS, JavaScript ni frameworks."[cite: 1]
- **Parte utilizada:** La distribución general de `<header>`, `<main>`, `<section>`, `<article>` y `<footer>`[cite: 1].
- **Cambios realizados por mí:** Reemplacé los textos genéricos por mis proyectos reales e ingresé los IDs correspondientes para la navegación[cite: 1].
- **¿Qué comprendí?** Comprendí cómo conectar los enlaces internos del `<nav>` usando los `id` de cada `<section>`[cite: 1].
- **¿Qué descarté y por qué?** Descarté scripts de JavaScript y enlaces a librerías externas para mantener el proyecto estático y simple[cite: 1].

## Consulta 2
- **Fecha:** 11/11/2026
- **Herramienta utilizada:** ChatGPT / Gemini
- **Objetivo:** Crear variables CSS para definir la paleta de colores y el diseño de tarjetas[cite: 1].
- **Prompt completo:** "Mi portfolio tiene estilo limpio y profesional, usa tonos azules y grises, y debe transmitir orden. Creá un CSS inicial con variables de color, tipografía legible, espaciados y tarjetas."[cite: 1]
- **Parte utilizada:** El bloque `:root` y la clase `.tarjeta`[cite: 1].
- **Cambios realizados por mí:** Ajusté los códigos de color en hexadecimal para que coincidan con mi paleta de planificación[cite: 1].
- **¿Qué comprendí?** Aprendí a declarar y reutilizar variables CSS con la sintaxis `var(--nombre)`[cite: 1].
- **¿Qué descarté y por qué?** Descarté una grilla compleja con Flexbox avanzado porque todavía no la necesitaba para la versión 0.1[cite: 1].
